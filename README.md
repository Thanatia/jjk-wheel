# 咒术回战 · 全能转盘模拟器（本地离线静音版）

参考 B 站热门「咒术转盘 / 人物能力拼图 / OC 死灭回游 / 1v1 斗蛐蛐」玩法打造的纯前端本地网页项目。**完全离线运行，不依赖任何外部 CDN，且已关闭所有语音播报与音频输出（纯文字与视觉动画）。**

## 目录结构

- `index.html`：主页面入口
- `styles.css`：暗色 / 亮色双主题样式与响应式布局
- `js/data.js`：人物拼图、OC 人生、1v1 斗蛐蛐与 Boss 卡池数据
- `js/app.js`：Canvas 阻尼转盘、SVG 五维雷达图、连携判定与文字战斗模拟器

## 运行方式

1. **直接打开（最简单）**：在文件管理器中直接双击 `index.html` 即可用默认浏览器游玩（脚本采用传统加载方式，无本地 `file://` CORS 限制）。
2. **本地服务（可选）**：
   ```bash
   python -m http.server 8080
   ```
   然后在浏览器访问 `http://localhost:8080`。

## 功能亮点

- **三大模式自由切换**：
  - 🧩 **人物能力拼图**：抽取「体格 / 咒力 / 生得术式 / 体术·黑闪 / 反转术式 / 领域展开」6 大部件，触发特殊连携词条并挑战漏瑚、真人、羂索、五条悟、完全体宿傩。
  - 🌀 **OC 咒术人生 / 死灭回游**：6 步随机生成原创角色履历与五维雷达图。
  - ⚔️ **原作人物 1v1 斗蛐蛐**：支持切换「全员乱斗 / 神仙局 / 下水道局」并随机抽取决战场地规则。
- **自定义卡池**：可在弹窗内自由增删当前轮盘词条，支持 JSON 导出与导入分享。
- **纯静音体验**：转盘指针动画、文字战报与高光特效均为纯视觉效果，无语音播报、无声音提示。
